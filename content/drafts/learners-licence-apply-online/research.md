# Research notes: How to apply for a learner's licence online

Internal working file. Not published.

## 1. Source videos (in my own words)

- **Primary:** LL Test Online 2026 | Learner licence test without visiting RTO (Sarkari DNA), https://www.youtube.com/watch?v=hSiDHH2OAzI. ~5 months old, Hindi. Parivahan → Driver/Learning Licence → state → "Online LL test"; enter application number + captcha; test now requires installing a Windows app ("SmartLock", a locked-down browser); earlier phone-based test no longer works; use a laptop or a Jan Seva Kendra; password resend; download LL after passing.
- **Second:** Driving Licence Apply 2026 | LLR first | ₹230 (Nel_AI), https://www.youtube.com/watch?v=ZPLB-Tv_UGE. 4 weeks old, Tamil. Aadhaar with linked mobile needed; Parivahan → online services → DL-related → Tamil Nadu → Apply for Learner Licence; LL first, then wait 30 days before DL; steps: application details, upload documents, fee (~₹230–250 in TN); download online.
- **Third:** Apply for learner licence online 2026 (Flight Information), https://www.youtube.com/watch?v=RQmp6y4RmnU. 1 day old, Hindi. Application walkthrough.
