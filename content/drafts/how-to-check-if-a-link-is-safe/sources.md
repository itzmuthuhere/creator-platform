# Sources: How to check if a link is safe before you click it

One line per source actually consulted. Only list pages you opened and read.
Format: `- [Page title](url) — Publisher. Accessed YYYY-MM-DD. Used for: what it supported.`

## Primary / official

- [Safe Browsing site status](https://transparencyreport.google.com/safe-browsing/search?hl=en) — Google Transparency Report. Accessed 2026-10-03. Used for: what the site-status check does; billions of URLs examined daily; many unsafe sites are compromised legitimate ones.
- [How it works](https://docs.virustotal.com/docs/how-it-works) — VirusTotal documentation. Accessed 2026-10-03. Used for: aggregation of 70+ scanners and blocklists; a clean result isn't proof of safety; submissions are shared with the security community.
- [Sanchar Saathi](https://www.sancharsaathi.gov.in/) — Department of Telecommunications. Accessed 2026-10-03. Used for: Chakshu, the service to report suspected fraud communication.
