# Research notes: How to check if a link is safe before you click it

Internal working file. Not published.

## 1. Source videos (in my own words)

- **Primary:** How to Check If a Link Is Safe Before Clicking (1 Minute Tech), https://www.youtube.com/watch?v=2UpiA-bPcPs. ~7 months old. Hover to see the real URL; check domain spelling (paypa1, Amaz0n); long hyphenated domains suspicious; scan with VirusTotal; HTTPS/padlock doesn't mean safe (free certificates).
- **Second:** Email & URL Analysis | Detect Phishing Links Like a Cybersecurity Analyst (SYED FAYAJ), https://www.youtube.com/watch?v=PH7eXIrxPv4. ~1 month old. CyberChef (decode/defang), PhishTank (community phishing DB; no result ≠ safe), URL-to-screenshot tools, urlscan.io (redirect chain, IPs, screenshot).
- **Third:** Is This Link SAFE? URL, QR code (wizdom village), https://www.youtube.com/watch?v=Ey5wWreXXZQ. ~3 months old, Hindi/Urdu. Pastes links/QR images into an AI chatbot and asks if safe. CORRECTED/not recommended: chatbots can't reliably verify live sites and may hallucinate.
