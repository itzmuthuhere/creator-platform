# Sources: How to check laptop battery health on Windows

One line per source actually consulted. Only list pages you opened and read.
Format: `- [Page title](url) — Publisher. Accessed YYYY-MM-DD. Used for: what it supported.`

## Primary / official

- [Powercfg command-line options](https://learn.microsoft.com/en-us/windows-hardware/design/device-experiences/powercfg-command-line-options) — Microsoft Learn. Accessed 2026-10-03. Used for: `/batteryreport` (HTML report in the current path, `/output`, `/duration`), and `/energy` (energy-efficiency and battery-life analysis, run when idle, 60-second default).

## Reputable secondary

- [BU-808: How to Prolong Lithium-based Batteries](https://batteryuniversity.com/article/bu-808-how-to-prolong-lithium-based-batteries) — Battery University (Cadex). Accessed 2026-10-03. Used for: heat above 30°C; capacity loss when kept at 100% (80% after a year at 25°C, 65% at 40°C); shallower discharges give far more cycles; no memory effect or need for full discharges; storage at partial charge.
- [A feature Windows 11 should have had on release is finally rolling out](https://www.xda-developers.com/a-feature-windows-11-should-have-had-on-release-is-finally-rolling-out-says-microsoft/) — XDA Developers, 28 Feb 2026. Accessed 2026-10-03. Used for: battery percentage and coloured icons in Windows 11 (KB5077241) and where to turn on the percentage.

## Source videos

- [Windows 11 Battery Health Check | Read Battery Report, Cycle Count & When to Replace Battery](https://www.youtube.com/watch?v=Q8Cu_-yXlEk) — CrackTheWindows (YouTube). Accessed 2026-10-03. Used for: a real report's figures (design 51,310 mWh, full charge 41,514 mWh, 217 cycles, runtime estimates) and rule-of-thumb thresholds (attributed). Its "full calibration every 2–3 months" tip is corrected.
- [How to Check Battery Health on Windows 11](https://www.youtube.com/watch?v=pRnsFlh8hNw) — Quick Tutorials (YouTube). Accessed 2026-10-03. Used for: where the report is saved; that readings fluctuate.
- [Check Your Laptop's Battery Health using CMD](https://www.youtube.com/watch?v=fFCBvfO0k5w) — Buzz2day Tech (YouTube). Accessed 2026-10-03. Used for: the same method (Hindi).
