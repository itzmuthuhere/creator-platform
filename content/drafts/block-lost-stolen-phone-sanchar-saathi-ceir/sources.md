# Sources: How to block a lost or stolen phone with Sanchar Saathi (CEIR)

One line per source actually consulted. Only pages opened and read are listed.

## Primary / official

- [CEIR home page, services, dashboard, FAQ and state statistics](https://www.ceir.gov.in/Home/index.jsp) — Department of Telecommunications / C-DOT. Accessed 2026-09-29. Used for: the four services, the blocking and unblocking procedure, 24-hour blocking, the TRAI 24-hour SMS rule, EIR/CEIR explanation, IMEI per SIM slot, state-police block message, national and state statistics (as of 24-09-2026).
- [CEIR request for blocking lost/stolen mobile (form)](https://www.ceir.gov.in/Request/CeirUserBlockRequestDirect.jsp) — DoT / C-DOT. Accessed 2026-09-29. Used for: form fields and which are mandatory, prerequisites pop-up (IMEI "if available"), ID proof options, declaration.
- [Sanchar Saathi: CEIR services](https://sancharsaathi.gov.in/Home/ceir-services.jsp) — DoT. Accessed 2026-09-29. Used for: confirming the same four services are reachable from Sanchar Saathi.
- [Google Find Hub web tool](https://www.google.com/android/find) — Google. Accessed 2026-09-29. Used for: the address readers use to locate or lock an Android phone.
- [Find, lock, or erase a lost Android device](https://support.google.com/android/answer/6160491?hl=en) — Google. Accessed 2026-09-29. Used for: Find Hub name, ring / mark as lost / factory reset, requirements, device disappears from Find Hub after reset, Find Hub network.
- [Protect your data if your device is stolen](https://support.google.com/android/answer/15146908?hl=en) — Google. Accessed 2026-09-29. Used for: Theft Detection Lock, Offline Device Lock, Remote Lock, Identity Check, settings path.
- [Find the serial number or IMEI on your iPhone, iPad, or iPod touch](https://support.apple.com/en-us/108037) — Apple. Accessed 2026-09-29. Used for: IMEI location in Settings, Apple Account device list, packaging.
- [Mark a device as lost in Find My](https://support.apple.com/en-sg/guide/findmy-mac/fmm0e3934777/mac) — Apple. Accessed 2026-09-29. Used for: what Mark As Lost does (lock, message, payment cards suspended).
- [About Stolen Device Protection for iPhone](https://support.apple.com/en-in/120340) — Apple. Accessed 2026-09-29. Used for: biometric-only actions away from familiar places, one-hour security delay, settings path.
- [Jio lost SIM: suspend, locate and PUK](https://www.jio.com/selfcare/lost-login/) — Jio. Accessed 2026-09-29. Used for: the page offers Suspend, Locate and Get PUK code for a lost Jio SIM.
- [How to block a stolen or lost Airtel SIM card](https://www.airtel.in/blog/prepaid/how-to-block-airtel-sim-card/) — Airtel. Accessed 2026-09-29. Used for: Airtel blocking numbers, store verification, replacement SIM.
- [Delhi Police Lost Report app FAQ](https://lostfound.delhipolice.gov.in/LostApp/faq.pdf) — Delhi Police. Accessed 2026-09-29. Used for: lost report is not an FIR; theft goes through e-FIR.
- [Delhi Police property theft e-FIR](https://propertytheft.delhipolice.gov.in/) — Delhi Police. Accessed 2026-09-29. Used for: example of an online theft e-FIR facility.

## Reputable secondary

- [Sanchar Saathi](https://en.wikipedia.org/wiki/Sanchar_Saathi) — Wikipedia. Accessed 2026-09-29. Used for: portal launch (May 2023), app launch (January 2025), 2025 pre-install order and withdrawal.
