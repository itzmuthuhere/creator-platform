A laptop with 8GB of RAM that felt perfectly fine three years ago can feel sluggish today running the exact same kind of tasks, and the laptop is not what changed. Operating systems, browsers, and the everyday apps most people leave running in the background have all gotten heavier, and that shift has pushed the comfortable RAM baseline for 2026 well above what most buying guides still recommend.

## The operating system itself takes a bigger cut now
Modern versions of Windows, macOS, and ChromeOS all run more background services, indexing, sync processes, and security features than their equivalents did five years ago. That baseline overhead eats into available memory before you have opened a single app, which is part of why a laptop that felt fine on 8GB a few years back can feel noticeably tighter running the current version of the same operating system.

## Your browser is probably the biggest memory user you own
Every open browser tab runs largely as its own process with its own memory allocation, and extensions add further overhead on top of that. For most people today, especially anyone who works with a dozen or more tabs open across research, email, and web apps, the browser alone can be the single largest consumer of memory on the entire machine, ahead of any actual application.

## Electron-based apps add up
Slack, Microsoft Teams, Discord, Notion, and a long list of other everyday apps are built on Electron, which essentially bundles a full browser engine inside each app. Each one individually can use several hundred megabytes to over a gigabyte of memory just sitting open in the background. Running three or four of these alongside a browser with many tabs open is a completely normal work setup, and it adds up fast.

## Soldered RAM changes how you should buy
A large share of modern thin-and-light laptops solder RAM directly to the motherboard, meaning there is no upgrade path after purchase, unlike older laptops with a removable RAM slot. If a laptop you are considering has soldered memory, buy for what you expect to need over the machine's full lifespan, not just for today's workload, since there is no fixing this decision later without replacing the whole laptop.

## Why Closing Tabs Manually Isn't a Real Long-Term Fix
Constantly closing tabs and quitting apps to free up memory treats the symptom, not the actual mismatch between available RAM and modern usage patterns. The moment you're back to a normal workday, the same tabs and apps reopen and memory pressure returns. Buying enough RAM upfront removes the need for this ongoing manual management entirely.

## How to Actually Check What's Using Your RAM Right Now
Windows Task Manager's Memory tab and macOS Activity Monitor both show real-time usage broken down by app and process. Sort by memory instead of CPU and you'll see which browser tabs or background apps are the real culprits. Worth checking once on your current machine before assuming you need an upgrade — sometimes the bottleneck is a single misbehaving app, not a genuine overall shortage.

## Why Swap and Virtual Memory Don't Fully Solve a RAM Shortage
When physical RAM fills up, the operating system uses disk space as overflow — called swap or virtual memory. This technically prevents a crash, but it's dramatically slower than real RAM, even on a fast SSD. That's exactly the sluggish, laggy feeling people associate with an "old" laptop that's just memory-starved, not underpowered elsewhere.

## What This Means If You're Buying for Someone Else
Choosing a laptop as a gift or for a family member who isn't technical themselves? Default to 16GB instead of the cheaper 8GB configuration. It avoids a frustrating slowdown they won't know how to diagnose or fix later, especially since soldered RAM configurations leave no upgrade path to correct an undersized choice after the fact.

## Who doesn't need more than 8GB
A secondary laptop used almost entirely for a single task at a time, document editing, video calls, or light browsing with very few tabs, can still work reasonably on 8GB. The problem is less about single-task performance and more about how quickly modern usage patterns drift into multitasking without anyone planning it that way.
If the budget stretches to it, and especially if the RAM is soldered in, treat 16GB as the default for 2026 rather than an upgrade you talk yourself out of. 8GB still works, but it belongs to light, single-task use now, not to the general recommendation it used to be.
