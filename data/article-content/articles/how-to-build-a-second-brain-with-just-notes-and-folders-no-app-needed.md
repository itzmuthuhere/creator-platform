A lot of people have tried building a 'second brain' by downloading Notion, spending a weekend setting up databases and templates, and abandoning it a month later with nothing to show for it. The tool was never really the bottleneck. What makes a note system useful long-term is a small, consistent structure for where information goes and how you find it again — and that structure works just as well in the Notes app already on your phone, a folder of plain text files, or a stack of labeled notebooks.

## Start with four folders, not forty
The biggest reason people abandon note systems is over-categorization: a folder for every possible topic, most holding one file. Use four broad buckets instead. Active covers anything tied to something you're currently working on. Reference covers things worth keeping but not acting on right now, like a warranty PDF or a note on how your building's water schedule works. Someday holds half-formed ideas and plans. Archive holds finished projects and dead ends, kept purely so you can search them later. Everything you write fits one of these four. When a project ends, its whole Active folder moves into Archive. That's the entire maintenance routine.

## Use one inbox, always
Don't try to file things perfectly the moment you capture them. Deciding exactly where a thought belongs is the friction that kills the habit before it starts. Keep a single Inbox file or folder. Anything new goes there first, no matter what it is. Filing happens later, in a separate step, when you're not mid-thought and can judge whether something is Active, Reference, or Someday.

## Name files so search does the filing for you
A folder structure only helps until you have a few hundred files in it, at which point browsing breaks down and search takes over. Make search work by naming files consistently: date first in YYYY-MM-DD format, then a plain-language topic. A file named 2026-03-14-landlord-deposit-agreement will surface instantly when you type 'deposit' months later, even if you've forgotten which folder you put it in. Consistent naming matters more than clever categorization, because it's what your future search query will match against.

## Run a five-minute Friday triage
Once a week, empty the Inbox. For each item, ask one question: is this still relevant? If yes, move it to Active, Reference, or Someday. If no, delete it or move it to Archive. This is the only point where the system requires deliberate thought, and five minutes a week is enough because you're triaging, not reorganizing everything from scratch.

## Handling Notes That Belong in More Than One Bucket
A note occasionally straddles two categories — a half-finished idea that's also technically active work. Resist creating a fifth bucket or a tagging system to handle this edge case. Pick whichever bucket you'd search for it under first and put it there. The four-folder system stays fast because it doesn't try to be perfectly precise about every borderline case.

## Why Plain Text Ages Better Than a Proprietary App's Format
Notes stored as plain text or in a basic native app format remain readable regardless of what happens to the app itself years from now. A note trapped inside a specific app's proprietary database format becomes hard to migrate if that app changes its pricing, shuts down, or simply stops being the tool you want to use. Worth weighing durability against features when picking where a second brain lives long-term.

## A Simple Test for Whether the System Is Actually Working
Once a month, try to find something you filed weeks earlier using only your naming convention and search, not by browsing folders from memory. If you can't find it within thirty seconds, that's a signal your naming habit needs tightening, not a sign you need a more complicated system. The fix is almost always more consistent naming, not more structure.

## Starting With What You Already Have Instead of a Blank Slate
Instead of starting a second brain from zero, importing or transcribing a handful of notes you already reference often — a recipe you keep looking up, a set of instructions you repeat — gives the system immediate, visible usefulness in its first week. That does more to build the habit than an empty folder structure waiting to be filled.

## Why This System Works Across Any Note App You Already Use
The four-folder structure and consistent naming convention don't depend on any specific app's features, which is precisely the point, they translate directly whether you're using your phone's built-in Notes app, a folder of plain text files synced through any cloud drive, or physical labeled notebooks. Choosing based on whatever tool you already open without thinking, rather than searching for the "perfect" app first, removes the biggest reason these systems stall before they start, since the search for a perfect tool is itself a form of procrastination on the actual habit that matters.

## What to Do When a Single Note Grows Too Large
A note that keeps growing, a running project log, a long-running reference document, eventually becomes unwieldy to search within itself even with good naming. Splitting it into dated sub-notes once it crosses a length that's hard to scan, rather than letting one file balloon indefinitely, keeps each individual file fast to open and search, which matters more for daily usability than keeping everything in one place out of a misplaced sense of tidiness.

## Handling Notes That Reference Each Other
A note that links back to an earlier one, a project update that references a decision made weeks before, benefits from a simple, consistent way to point back, either the exact filename or a brief unique phrase copied from the earlier note, so that a search later surfaces both connected pieces together rather than treating them as unrelated entries that happen to share a topic.

## Revisiting Someday and Archive Once a Season
Beyond the weekly five-minute triage, a slower quarterly pass through the Someday and Archive folders catches ideas that have become relevant again, or archived projects worth referencing for a new one, a check that the weekly triage is too fast-paced to naturally surface on its own.

## Why Starting Small Beats Trying to Migrate Everything at Once
Attempting to reorganize years of scattered notes into the new structure all at once is the fastest way to abandon the system before it ever proves useful, applying the four folders only to new notes going forward, and migrating old material gradually if it ever comes up again, keeps the effort proportional to what's needed.

## Handling Notes Captured on the Go Versus at a Desk
A voice memo dictated while walking or a quick photo of a whiteboard captured on the go often sits awkwardly outside the normal typed-note workflow. Treating these the same as any other inbox item, transcribing or briefly summarizing them into text during the weekly triage rather than leaving them as untitled audio or image files, keeps them searchable alongside everything else instead of becoming an untouched, unsearchable pile.

## Why Consistency Matters More Than Which Exact System You Pick
Plenty of note-organizing methods work reasonably well, the specific value of this one is that it's simple enough to maintain for years rather than being abandoned after a few enthusiastic weeks, which is ultimately the only real test any personal system needs to pass.

## Why Search Quality Depends on More Than Just File Names
Beyond consistent naming, keeping actual sentences inside a note, not just bullet fragments, gives search more to match against later. A note that's just "deposit issue landlord" is far harder to find with a natural-language search months later than one that reads "landlord disputed the deposit return over a wall scratch," even though both took the same few seconds to write.

## What to Do If You've Tried and Abandoned Note Systems Before
A history of abandoned Notion workspaces or half-filled notebooks isn't a sign this approach will fail too, it's usually a sign the previous systems asked for more upfront structure than any single person needs. Starting smaller than feels necessary, four folders and one naming rule, is precisely the correction for that pattern.

## What doesn't belong in the system at all
Not everything needs to be captured. Reminders with a fixed time belong in a calendar or alarm, not a note. Quick reference facts you'll never need to search for later, like a one-time OTP, don't need a home. A second brain is for things you'll want to find or reread — not a dumping ground for everything that crosses your mind. Being selective about what enters the system is what keeps it usable a year in, rather than becoming another junk drawer you stop trusting.
If you're already taking notes somewhere, you don't need to migrate anything to try this. Add the four folders, start using the naming rule on your next few files, and give it a couple of weeks — most of the benefit shows up once you have enough files that search has something to work with.
